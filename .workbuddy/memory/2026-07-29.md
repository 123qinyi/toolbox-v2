## 首次 push 及问题修复
- commit `9b38583`（lucide-react 降级）已成功 push 到 GitHub main
- **根因定位**：PortableGit 系统级 gitconfig 配了 GCM（Git Credential Manager），GCM 凭据缓存在 Windows 凭据管理器（机器绑定），迁移后丢失。GCM 又覆盖了 `credential.helper store`，导致 git 认证链断裂 → 401
